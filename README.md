# BreynerTejada1020416500

Proyecto de calculadora básica en Python con flujo de CI/CD configurado mediante GitHub Actions.

## Descripción

Calculadora con operaciones básicas: suma, resta, multiplicación y división.

## Ejecución

```bash
python calculadora.py
```

## Tests

```bash
pip install pytest
pytest test_calculadora.py -v
```

## CI/CD

Cada commit activa automáticamente el flujo de GitHub Actions que ejecuta las pruebas.
